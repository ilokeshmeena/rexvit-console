# RexVit Console

RexVit Console is a production-oriented desktop API explorer and runner for local OpenAPI and Swagger specifications.

## Stack

- Tauri v2
- React 19
- TypeScript
- Vite
- Zustand
- TanStack Query
- Tailwind CSS
- shadcn/ui-style primitives
- SQLite
- OpenAPI 3.x / Swagger 2.0 discovery

## Scripts

```bash
pnpm install
pnpm dev
pnpm tauri:dev
pnpm test
pnpm typecheck
```

Rust and the Tauri prerequisites are required for native desktop builds.
